# CodeAlpha Internship - Task 1: Simple E-commerce Store

A Full-Stack e-commerce application demonstrating backend API integration, user authentication, and dynamic frontend rendering.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Node.js, Express.js
- **API:** RESTful API for products and authentication

## How to Run
1. Open the terminal in the `backend` folder.
2. Run `npm install` (if you have dependencies) or simply `node server.js`.
3. Open `index.html` in your browser.
